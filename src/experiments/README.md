# Expériences

Les calculs d'évaluation reproductibles sont exécutés par
`scripts/regenerate_all.py`. Le classeur historique `I_evaluation.py` est
conservé dans `scripts/`; sa régénération complète nécessite des rapports de
vérification et des exports de timing/détection des parties F à H qui ne sont
pas tous présents dans les sources livrées.
